# FastCare Laundry — Hero Section Variants

A modern UI exploration project for **FastCare Laundry**, focused on creating three unique and premium hero-section concepts while preserving the brand's existing visual identity.

The goal was to explore how the same laundry-service brand can be presented through different modern UI directions instead of using a traditional website hero layout.

---

## ✨ Project Overview

This project contains **3 different hero-section concepts** designed around FastCare Laundry's existing:

- Brand colors
- Typography
- Content style
- Laundry-service identity
- Premium & trustworthy visual language

Each variant uses a different visual approach while keeping the FastCare brand recognizable.

---

## 🎨 Hero Variants

### 01 — 3D Laundry Orbit

A spatial hero concept built around a floating laundry visual.

**Highlights:**

- 3D perspective image
- Floating information badges
- Orbit-inspired decorative elements
- Subtle parallax interaction
- Premium depth and shadows
- 24-hour delivery highlight
- Modern CTA treatment

**Design direction:**

> Premium Laundry Service × Spatial 3D UI

---

### 02 — Laundry Experience Portal

A futuristic glassmorphism concept where the laundry visual appears inside a spatial portal.

**Highlights:**

- Glassmorphism
- Layered depth
- Spatial visual treatment
- Soft blue & green accents
- Interactive service journey
- Pickup → Clean → Inspect → Deliver flow
- Minimal and clean typography

**Design direction:**

> Premium Service × Glass Spatial Experience

---

### 03 — Smart Pickup Experience

A conversion-focused hero inspired by modern product interfaces.

The main visual combines a laundry image with a floating booking interface.

**Highlights:**

- 3D booking panel
- Glass UI
- Pickup scheduling interface
- 24-hour delivery indicator
- Floating service badges
- Strong conversion-focused CTA
- Interactive hover states

**Design direction:**

> Laundry Service × Smart Booking Interface
